👨‍💻 关于博主

Hi，欢迎来到我的个人技术博客！我是 Leeyunhe（GitHub: @Leeyunhe）。

一名深耕于计算机底层架构、工业通信与跨平台系统研发的技术开发者。主要专注于 嵌入式 Linux / 国产操作系统底层与通信开发、工业测控上位机与跨平台 GUI 开发、现场总线与协议转换网关 以及 计算机图形学（OpenGL / OpenGL ES） 等技术领域。

崇尚“知其然，更知其所以然”的工程探索精神。技术体系涵盖工业边缘硬件（ARM / 国产架构）、多总线报文流转、多媒体驱动管线到工业级桌面测控系统，享受用高可靠代码驱动软硬件协同运转的极客乐趣。

💻 核心编程语言与基础

C / C++ (指针/内存模型/现代C++) C# (.NET / .NET Framework) GLSL (着色器语言) Shell / Bash Markdown

🖥️ 上位机与跨平台桌面开发

C# WinForm / WPF 桌面客户端 监测与控制上位机 / 自动化测试系统 Qt / C++ Windows 桌面程序 国产操作系统 Qt 适配开发 (银河麒麟 Kylin OS)

🔌 嵌入式、国产化平台与底层通信

边缘计算硬件 (RK3588 / 国产飞腾 D2000) 嵌入式 Linux 系统 (Ubuntu / 银河麒麟) 通信协议转换与数据网关转发 (串口转网口) 高性能报文解析、协议封装与数据流转 CAN / 工业现场总线通信 状态逻辑控制、保护机制与总控交互协议 本地数据持久化存储与轻量日志系统 Linux 底层多媒体与驱动 (V4L2 / G2D / YUV)
